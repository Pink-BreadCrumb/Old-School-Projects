Project Description
Create a Python program where two players compete in a Rock-Paper-Scissors tournament. The game should track scores across multiple rounds, determine a winner, and display final statistics.


Requirements
Your program must include:

    Functions: At least one custom function (e.g., `determine_winner()`, `play_round()`)
    User Input: Collect both players' names and their rock/paper/scissors choices using `input()`
    Conditionals: Use if/elif/else to determine who wins each round (rock beats scissors, scissors beats paper, paper beats rock)
    Loops: Use a loop to play multiple rounds (at least 3 rounds, or best-of-5/best-of-7)
    Score Tracking: Keep track of each player's wins and display running score
    Game Features: Announce round winner, display final winner, show total statistics
    Code Quality: Include comments and meaningful variable names
